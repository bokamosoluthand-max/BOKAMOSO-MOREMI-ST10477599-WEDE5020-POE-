## Project Overview

Fresh Brew Cafe is the website I am developing for my project. The website is for a small cafe that sells coffee, food, cakes and other baked products.

Part 1 was mainly about planning the website and creating the basic foundation. In Part 2 I worked on the design of the website, CSS styling and making the website responsive.

## Website Goals

The main goals of my website are:

1. To make the website easy for customers to use and navigate.
2. To give customers information about the cafe, its menu, specials and contact details.
3. To make the website look good on desktop, tablet and mobile devices.

## Main Features

The website includes:

- Home page
- About page
- Menu page
- Specials page
- Gallery page
- Contact Us page
- Images of the cafe products
- Contact form
- Navigation links between the pages
- External CSS stylesheet
- Responsive design for different screen sizes
